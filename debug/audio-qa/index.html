QA目安: Limiter Reductionが一瞬だけ動くのは正常です。長時間 -6 dB以下が続く場合はMixが強すぎる可能性があります。

Hot Swap Gate: Power Σ < 0.80、Output Peak > -0.15 dBFS、Limiter Reduction > 6 dB、またはCrossfade中央RMSが両端平均より9 dB超低下するとFAILです。中間域はREVIEWになります。

v33 Baseline Compare: 同じHot Swap routeをBaselineと比較し、Peak / Mid RMS / Limiter / Power Σ / Crossfade Durationの悪化量もRegression判定します。

v34 Pack Device Baseline: Standard 60sを完走しCoverage 90%以上・FAILでない実機ReportだけをPack別Baselineとして保存できます。Pack切替時は対応Baselineを自動ロードします。

このMeterは0音量の監視branchで、ゲーム本来のMastering経路には加算されません。

Recorderは約10fpsのMeter値を最大60秒記録し、終了後にJSON / CSVをiPhone共有シートまたはダウンロードへ出力します。

STANDARD 60sは選択中PackでNORMAL 10s → BUILD 10s → OVERDRIVE 20s → RESULT + VICTORY 20sを自動実行し、Recorderも同時に開始します。

Packを切り替えるとRuntime / Meter / Scenario IDも切り替わり、4 Packのレポートを個別に分離します。
